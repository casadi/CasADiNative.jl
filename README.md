# CasADiNative.jl

Native Julia bindings for [CasADi](https://casadi.org), without a Python bridge.

```julia
import CasADiNative as ca

x = ca.SX.sym("x")
f = ca.Function("f", [x], [x^2 + 1])
f(3.0) # 10
```

This is the **official** native binding, generated by a SWIG `-julia` backend.
(The unrelated [`CasADi.jl`](https://github.com/SciML/CasADi.jl) in the General
registry is a PythonCall-based wrapper.)

Conventions mirror CasADi's Python/MATLAB API: `ca.MX.sym(...)`, `'` transpose,
`A \ b`, 1-based indexing, broadcasting (`.*` is elementwise), positional option
`Dict`s, and method-style calls (`f.jacobian()`, `opti.solve()`).

## Status

Beta. This package is the handwritten ergonomics layer and nothing else. The
binaries and the 600 KB SWIG-generated module come from two JLLs built by
[Yggdrasil](https://github.com/JuliaPackaging/Yggdrasil):
[`CasADi_jll`](https://github.com/JuliaPackaging/Yggdrasil/tree/master/C/CasADi)
(libcasadi plus the solver/integrator plugins) and
[`CasADiJulia_jll`](https://github.com/JuliaPackaging/Yggdrasil/tree/master/C/CasADiJulia)
(the wrapper `libcasadi_wrap` next to the generated `casadi.jl`).

The package version tracks the CasADi release it binds.

Because the wrapper inlines Julia C API accessors tied to the minor ABI, it is
compiled once per Julia minor, and `CasADiJulia_jll` therefore exists only for
Julia 1.10, 1.11 and 1.12.
